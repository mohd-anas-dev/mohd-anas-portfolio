## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mohd-anas-dev/mohd-anas-portfolio.git
```

### 2. Navigate into the project

```bash
cd YOUR_REPOSITORY
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

---

## Production Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Environment Variables

If environment variables are required, create a `.env` file in the root directory.

Example:

```env
VITE_EXAMPLE_VARIABLE=your_value
```

Never commit your `.env` file or expose private credentials in the repository.

## Design Philosophy

The portfolio follows a minimal and interaction-driven design approach.

Rather than relying heavily on traditional UI elements, the experience focuses on:

* Typography
* Spacing
* Motion
* Composition
* Micro-interactions
* Smooth transitions
* Visual hierarchy

The goal is to make the interface feel intentional while maintaining performance and usability.

---

## Performance

Performance is considered throughout the development process, including:

* Optimized image assets
* Lazy loading where appropriate
* Controlled animation complexity
* Responsive layouts
* Production builds with Vite
* Minimal unnecessary dependencies

---

## Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile

The navigation and interactions adapt specifically for smaller screens rather than simply shrinking the desktop layout.
